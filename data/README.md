# Application icon

The original artwork is `UWCC Stingray Reef Icon.png` at the repository root.
Run `python3 tools/prepare_icons.py` to regenerate the standard desktop sizes in
`icons/hicolor/` and the bundled Qt icon in `uwcc/assets/uwcc.png`.

Both desktop launchers use the `uwcc` icon name. The Python package includes its
own icon so source-checkout and Python installations also display the artwork.
